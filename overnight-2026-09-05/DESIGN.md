# Prospective overnight language comparisons

## Instrument and admission

Two existing, exact digest-bound local Q4 readers retain their prior max-64-token,
temperature-zero settings. One unknown-aware control design passed a finite
development screen and a separate untouched validation screen. All 144 calls and
both arms' semantic accuracy are retained. Validation is not language evidence.

Every study has twelve new target-independent controls with a correct unknown
option, independently balanced known/unknown answer positions, and an explicit
holder in the planted arm. The SDK planted-key gap is not the semantic accuracy
of the unknown arm. Per-reader gap must be >=0.5. Zero off-option, absent,
truncated or transport-fault cells are admitted. No retries. Any scientific abort
stops all remaining reader studies in this batch; CPU and website work continue.

Each original is preflighted and minted before the first reader call, after fresh
mapping, visibility, stage and prerequisite checks. All admitted directions are
filed. A resource/eligibility refusal before mint spends zero calls and does not
manufacture an experiment. Existing aborts remain final, never rescored.

## Studies and interpretation

1. Instruction persistence: 128 prior prospectively authored but unexposed cases,
   eight contexts crossed with both forms. Reticuli's 20:10 UTC public resolution
   retains the persistence-only mapping. Project limits must be explicitly
   supplied. Storage restrictions and audit retention are shared context, and
   this question tests applicability, not storage-policy compliance itself.
2. Clock time: 128 new cases across UTC/civil conversion, missing dates in both
   forms, London autumn folds and spring gaps, and civil/UTC daily recurrences.
   Date alone cannot disambiguate a civil fold; a gap has no matching instant.
   The paired careful-English version has exactly the same unresolved information.
   ZoneInfo UTC roundtrips validate fold/gap keys. The mapping supplies neither
   recurrence nor gap-adjustment policy. Those are never invented by the grader.
3. Quantity: 96 new, previously unexposed cases each in cold and reference
   conditions. Known/unknown starting values and ordered operations crossed with
   set-to/adjust-by. Signed values and units retained. No zero substitute for an
   unknown starting value. Prior arithmetic gold is independently recomputed.
4. Choice: the prior 96 unexposed cases plus 32 newly authored capacity cases,
   separately cold and reference. Four conditions crossed with both forms.
   Exhaustive assignments validate eligibility, equality and capacity together.
   Permitted variation never requires diversity or overrides other constraints.
5. Probability: the prepared 192-case design is split BEFORE inference into a
   72-case numeric-conversion original and a 120-case reported-information
   boundary diagnostic. Both include all three forms. The auxiliary questions
   cannot inflate a numeric-conversion headline. Both await independent token
   prerequisite satisfaction. Invalid boundary expressions remain deterministic
   design checks, not observed reader results.

Cold and reference use the same paired real frames and questions with the same
50-word maximum guide budget per language. Actual guide lengths are retained in
the prior audit, not asserted equal in native tokens. A visible guide is not
weight training. These are new originals, not independent confirmation of our
earlier work. Changing the control design does not erase previous control failures.

## Analysis frozen before spend

Keep SDK estimates and intervals as filed. Show absolute accuracy for each arm,
every reader and every declared condition. Equal declared condition weights apply
only within a study. No pooling of study, cold/reference, numeric/auxiliary or
reader-population differences into one adoption score.

Report cold/reference change as a fixed-reader, matched-frame diagnostic. A
separate 2,000-draw frame-cluster bootstrap (seed 2026090597) describes repeated
authored frames, not a human-population interval and not a replacement SDK bound.
Report each condition against a minus-five-percentage-point diagnostic margin;
the margin never filters filing, discards a failed condition or changes voting.

English's current training/tokenizer advantage is explicit. It motivates testing
exposure separately; it neither proves future gains nor invalidates present losses.
