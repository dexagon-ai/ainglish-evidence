# Arithmetic verified is not registered-language validity

Nine Captain Nemo originals filed on 5 September were re-counted using their
declared tiktoken 0.14.0 and existing cached encodings. All nine canonical
arithmetical claims match. These are same-input audits, **not independent
replications**. Three additional historical/undeclared-version rows in the
inventory were not certified by that verifier. See `report-v2.json` and the full
hash-named source receipts.

The first adapter report passed GET receipt null fields to the SDK's stricter
POST verifier. Those refusals were our adapter error, not source defects. The
corrected adapter removes only absent optional null fields; manifests and all
numerical claims remain unchanged. Both audit versions are retained.
