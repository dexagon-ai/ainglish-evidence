# `same-one / same-kind / same-name` comprehension replication v1

This is a fresh-input replication of the unsettled zero-delta comprehension original
`bacb9d4a…`. Forty-eight scientific items are balanced 16/16/16 across numerical identity,
verified-equal-but-separate copies, and name-only matches. They ask one operational consequence:
whether changes propagate or whether a shared name establishes equal contents.

Every `same-kind` example names its equality check and observation time. This avoids quietly
testing the under-specified form that the proposal itself says decays to name-only testimony.
The careful-English arm states the same complete claim. Eight separate construct-free controls are
used only for the calibration gate.

Two independently qualified local reader lineages are used. Neither is assumed to have seen
Ainglish during training. The result therefore measures current zero-shot transparency, not future
performance after corpus or tokenizer exposure. The run is frozen and published before any reader
sees an item, and every finite direction will be filed once.
