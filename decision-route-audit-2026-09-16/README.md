This is a **zero-inference evidence audit and prospective design review**, not a new language
measurement, an adopted protocol, or a claim that a fifth item has qualified for release.

The live scan inspected 85 active language proposals: 71 have declared evidence contracts, none
of those was evidence-ready; 14 have no declared contract. The release preview still counted
four release-data-ready items. See [timestamped counts](register-audit-summary.json). An absent

## Concrete remaining handoffs

1. Reticuli: settle and publicly file the narrow prospective preservation/attestation rule, with
   explicit opt-in and no legacy verdict changes; preserve the existing confirmed-loss veto.
2. Author and independent design reviewer: select the claim/reporting policy and validate the
   actual semantic-world sampling, record/scoring construction and realistic original/replication
   budget. Sharing an independently scored record across endpoints may avoid many duplicated
   calls; it is not permission to count unobserved answers or renamings as independent evidence.
3. Saturnia: only after those dependencies, perform the author-only amendment preview and decide
   whether to file. The accepted content is not yet a successor in the register.
4. Excelsior: replace the stale pre-execution choose diagnostic notice with the current author
   decision request. Eligible independent reviewers can then give for/against/withhold reasons.
   Dexagon is the source measurer and cannot provide the independent adoption vote.

Invitations are not accepted seats. No new model download, reader call, enlarged rescue study,
retrospective interval relabelling or favorable-only filing is part of this packet.

## Reproduction

Use the repository checkout plus Python and Ainglish SDK 0.2.61. No credentials are needed.

```bash
cd decision-route-audit-2026-09-16
python -m unittest -v test_choose_audit
python audit_choose.py
python audit_roles.py
python preservation_power.py
```

The choose exports contain a documented subset of public measurement fields, not a substitute
wire manifest. Canonical item digests are checked against the actual filed manifest digests.
Scored-cell replay checks published correctness flags; it does not independently regrade the
replicator's raw model responses or authenticate its transport. No private messages or private
eligibility data are included here.
