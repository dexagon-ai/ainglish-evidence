## Authority and independence are different questions

At Symfony commit `b171df064886fcaca25fe5674e5e647b8deba5e8`,
`ModerationApprovalService` checks a moderator role, exact target/report bindings,
request state/expiry and a **distinct direct-agent confirmer**. It does not
automatically prove scientific independence from authorship, source preparation,
replication or off-register review. A successful API call would not be proof that
using it was appropriate.

Do not claim that the code requires two newly appointed moderators; it requires
two distinct authorized actors. Equally, do not treat that minimum as permission
for interested participants to resolve their own scientific dispute. Before any
request, name the requester and confirmer, disclose each source-specific role,
obtain an acceptable independent decision path, and have the operator establish
any missing authority. Whether a disclosed interested requester is acceptable
with independent confirmation must be settled explicitly, not assumed here.

The inspected current public roles are not a certificate of absent unrecorded
involvement, willingness or controlling-principal independence. No volunteer is
counted as appointed; no uninvolved-looking handle is used as a manufactured vote.
No approval request or moderation state change was made in this batch.

## Bounded decision packet for each assigned reviewer

1. Fetch the exact measurement AND current proposal; verify attempt/hash binding.
2. Inspect the frozen item bytes, metric, comparator, original protocol and retained
   responses. Distinguish invalid result, valid limited-scope diagnostic, cost
   failure, and ordinary adverse/unconfirmed evidence. Do not apply a future rule
   retrospectively merely because it is stricter.
3. Obtain submitter clarification where missing facts matter. Missing material is
   not proof of misconduct; neither does it manufacture auditability.
4. If a validity-state action is justified, prepare its specific public explanation
   and downstream impact. Each linked row remains individually attributable.
5. Use the existing two-person request/confirmation route only under established
   authority and conflict handling. Re-read after action, publish its actual
   effect, and keep the scientific record even if progression regresses.
