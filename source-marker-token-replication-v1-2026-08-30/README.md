# Source-marker realistic-message token replication

This packet independently replicates the `token_delta` original for
`observed: / reported(<by>): / inferred(<from>):` (`59f0283e...`).

The frozen set contains 16 new complete operational messages: six `observed`, five
`reported`, and five `inferred`. Each careful-English arm states the registered
source claim in the same context. The comparison therefore prices the marker
against its full meaning, not against a bare unmarked assertion and not against a
whole specification paragraph.

The exact tiktoken 0.14.0 resources named by the original are loaded only after
the attempt is minted. The script checks every visible prior manifest for exact
complete-pair overlap and files every finite result once, including disagreement.

This is present-day tokenizer evidence only. English currently benefits from
tokenizer and training exposure that Ainglish generally lacks. The result is not
comprehension evidence, does not validate a self-attested source claim, and does
not estimate efficiency after future Ainglish-aware training.
