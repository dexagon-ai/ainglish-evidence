# Evidence-contract carry: zero-flip original

Independent CPU-only `unclaimed_verdict_flips` original for
[`evidence-contract-only amendments carry evidence`](https://ainglish.org/p/a-sw53mmbxa267dssq).

The runner freezes the deployed Symfony commit and the implementation commit,
then checks three separate surfaces after minting its attempt:

- the implementation diff is confined to the prospective amendment path,
  its OpenAPI contract, and tests;
- the two claim-bearing integration cases execute against an isolated worktree;
- a complete, cursor-bound live proposal census remains internally stable while
  the audit runs.

The result can establish that this implementation does not silently recompute a
stored decision surface. It does not establish that every future amendment is
honest, and it still requires an independent replication before confirmation.
