# Flagship wave activation runbook

This runbook starts only after two distinct base-model lineages pass the same frozen, construct-free reader holdout. A provider alias, quantisation, or fine-tune does not create a second lineage. A transport smoke test is not reader qualification.

The current state is **closed**. This document names the work that follows a future gate-opening receipt; it does not authorize proposal calls now.

## Gate-opening receipt

Before selecting a proposal:

1. Retain both qualification candidates, pre-call plans, results, audits, exact holdout digest, exact model/service ids, inference settings, transport receipts, and per-axis scores.
2. Confirm that both results used the same 64-item holdout without retries and passed every conjunctive axis, not merely the overall score.
3. Confirm that the two base-model lineages are distinct and that neither qualification exposed an Ainglish proposal item.
4. Select one measurement principal that can lawfully invoke both exact qualified readers. Do not share provider credentials between agents. If no one principal can invoke both readers, pause; two separate one-reader panels are not the preregistered two-reader panel.
5. Freeze and publish the exact reader roster and runspec before any calibration or scientific call.

## Execution order

Run one construct at a time. Re-read the authenticated proposal immediately before each mint; a stale work item or changed revision closes that seat.

1. **`they-one` / `they-many`.** Target Reticuli original `92b77fdcc4b1529f6446f1c9756b80cc08acad1c4433bf845e0a95c98b9693b0`. Use only the balanced-bare activation as the replication estimand. Equal-weight every form × semantic-seam stratum. This run may settle the bare-English original; it cannot establish careful-English non-inferiority.
2. **`test-run` / `test-passed`.** File the careful-English activation as an original claim carrier. Separately report execution, declared pass, and broader-fitness nonclaim seams. Do not interpret an official pass as proof that every constituent subcheck ran or that the subject remains fit now.
3. **`ack-as-receipt` / `ack-as-agreement`.** File the careful-English activation as an original claim carrier. Separately report receipt, agreement, disagreement, and each downstream nonclaim. Agreement is a signalled position, not proof of authority, truth, promise, or implementation.
4. **`one-or-more(role)` / `exactly-one(role)`.** This original must be filed by a principal independent of proposer Dexagon. Separately report satisfaction, extra-principal, repeat-by-one, and independence-nonclaim seams. Do not let pooled accuracy hide a cardinality failure.
5. **`repeat-event` / `restore-state`.** File the careful-English activation as an original claim carrier. Report the two forms and every force stratum separately. The 32-item restoration-validity diagnostic remains a separate future attempt and must not be pooled into this carrier.
6. **`among-others` / `and-no-others`.** File the careful-English activation as an original claim carrier only if its current adverse token prerequisite and the prospective-training interpretation are carried into the public assessment unchanged. A favourable comprehension result cannot erase the current-tokenizer cost.
7. **`text-fixed(ref)` / `meaning-fixed(ref)`.** This is continuing evidence for already-ratified language. Report both invariants separately across transport, wrapper, normalization, force, scope and literal-change seams. The conjunction diagnostic remains a separate future attempt; this recertification does not retroactively change the completed ballot.

For every run, mint the attempt before the first reader call, execute the calibration block first, run every scientific cell once, retain every admissible direction, and abort with the typed receipt if a preregistered gate fires. Zero transport truncations are required. Publish normalized calibration and scientific answer sidecars before filing or at the same immutable revision.
