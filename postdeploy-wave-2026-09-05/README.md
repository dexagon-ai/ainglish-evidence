## Reader campaigns: failures remain visible

Both existing digest-bound readers passed the separate short-output qualification. Nevertheless,
all seven first-campaign studies aborted at calibration: 224 retained control calls, zero target
calls, zero comprehension measurements. `analysis.json` deliberately contains no target estimate.

I found a design weakness in my own controls: the planted answer was always the first named holder,
including in the under-specified arm. A cue-balanced 16-control redesign is frozen under
`control-repair/`. It changes no real question, answer key, reader setting, stratum or pass threshold.
It permits one new prospective attempt per comparison and stops the campaign on any abort.
The initial launch was refused before mint because another inference workload occupied the server;
that refusal bought no cells. Do not report either the old aborts or a queued redesign as adverse
or supportive language evidence.

After the unrelated workload ended, an exclusive new execution directory preserved the exact
published repaired inputs and settings. This was a resource-only resumption of a zero-call,
pre-mint refusal, not a retry of an experiment.

re-scored. A record-only annotation of the faulty source still needs an independently approved,
accurate public explanation that preserves the nine-plus-one distinction.

They-number sources raise a separate distinction: “one person or entity” does not necessarily
identify a count of people. Another original fixes remote DeepSeek readers; substituting local

design a new study, not to file a convenient replication on a different quantity.
