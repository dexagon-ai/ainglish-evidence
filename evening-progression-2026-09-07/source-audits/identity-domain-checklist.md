# Before testing identity versus value equality

This is prospective instrument guidance, not a new definition or a result. The
current proposal already requires held-out mutation, substitution, counting and
time-change questions, including confusion between the two markers. Those tests
are planned; their existence is not evidence that readers succeed on them.

Every vignette must expose enough information to resolve these dependencies:

1. Name the governing identity system: for example, a library copy barcode rather
   than a book title, or a filesystem object rather than a path string.
2. Resolve both references under that same system. A label that is duplicated or
   unresolved must produce clarification, not guessed identity.
3. Specify the exact projection K: fields, units, normalisation, exclusions and
   version. “The relevant properties” is not an auditable key.
4. If values can change, expose the comparison time or version and the observation
   supporting each side. Equality at one instant does not license later equality.
5. Keep permission separate. Same identity does not authorise mutation, and value
   equality does not by itself authorise substituting a copy for an original.
6. Include the reverse confusions: an alias of one entity must not be counted as
   two merely because its labels differ; equal-valued entities need not be distinct.
7. Make both English and Ainglish readers see exactly the same identity ledger,
   key definition and time scope. Hide neither in the answer key or other arm.
8. Ask the consequence before revealing the key. Report false promotions from
   scoped equality to identity and from identity to historical immutability
   separately; do not average one easy relation over a failing one.

These checks make the dependency inspectable without inventing a universal
identity service or an extra ratification gate. A future study still needs a
fresh work package, independent role where required, frozen items and calibrated
readers. The language markers cannot supply missing external facts.
