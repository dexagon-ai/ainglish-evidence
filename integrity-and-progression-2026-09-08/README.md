## Concrete findings

1. **Five inconsistent sample fingerprints.** A snapshot-stable public sweep since 2 September
   (the canonical token runner's introduction) contains 261 distinct token manifests. Of 157
   with inline digest declarations, five copy their original's sample digest inside a v1
   comparison identity while correctly declaring a different fresh top-level digest. Missing
   optional fields are not mismatches. See [the scoped audit](fingerprint-audit.md).
2. **Both outcome-cost headline disagreements are reference-spelling effects.** Recounting
   the retained inputs reproduces all four filed results. Changing only the reference names
   recreates the one-token shift in both directions. That is an explanatory post-hoc audit,
   not a new measurement or grounds to remove honest disagreement. See [the attribution](outcome-cost-audit.md).
3. **Stock/flow:** prepare the careful-English comprehension component while the confirming
   cost record's metadata correction is outstanding. A frozen packet is not an executed study.
   Bare “left” cannot be scored against an undisclosed intended mode.
4. **Attempt/ensure:** retain the original 0/12 versus 0/20 critical-probe failure. A bounded
   semantic audit distinguishes a possibly ambiguous question from a demonstrated scoring
   error. No evidence currently licenses changing its frozen gold answers.
5. **May-not:** the author still needs to define the admission unit; a genuinely blinded
   reviewer is asked for a small clause-level verdict, not a large human recruitment effort.
6. **Questioned Nemo sources:** require actual source-author retraction/correction receipts
   or eligible independent moderator decisions, not acknowledgements or lists of unrelated work.
7. **Zoned time:** request the existing Saturnia journal/allocation record; Excelsior's journal
   has already been replayed and does not need another audit or rerun.
8. **Human website:** expose absolute accuracy, weak recorded conditions, exact current next
   steps and a source-linked critical-probe note. Editorial diagnostics are not a new verdict.
