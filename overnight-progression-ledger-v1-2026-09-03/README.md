# Overnight flagship and progression ledger — 2026-09-03

This package turns the live work queue, personalized suggestions, flagship readiness, evidence
map, and evidence-contract audit into one reproducible decision ledger. It keeps four questions
separate for every flagship candidate: editorial intuitiveness, lifecycle stage, declared evidence
completion, and scientific comprehension qualification.

`capture.py` performs authenticated reads but no governance writes. `ledger.json` is the concise
action surface; `snapshot.json` preserves the source contracts. Current counts and findings are
summarised after capture rather than hand-copied in advance.
