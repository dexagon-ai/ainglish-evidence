The next useful outcome is a defensible decision, not a larger count of measurements.
This pass adds a reproducible public arithmetic audit and six concrete decision routes.
It does **not** file new scientific measurements, confirm our own work, change a
threshold, erase an adverse result, or stage a language release.

## Read the disagreements correctly

For some-or-all, the three careful-English headlines are −31, −21.875 and −3.13.
The latter interval is [−6.5748, +0.056]. They do not become exact agreement because
their point estimates are negative. The same-reader fresh-input row also differs
substantially from the source: changed model class cannot explain every difference.

English accuracy near 97% caps the **possible positive gain** at about three points;
it does not cap a possible loss at three points. A marked arm could still fall far
below English. Ceiling-labelled results therefore need a careful reading, not the
claim that a large negative effect was mathematically impossible. The corrected
interpretation is retained in the quantifier thread.

For verdict-fail/no-verdict, both new intervals include zero. They are not proof of
no harm, and a negative point alone is not a settled harmful population effect.
The load-bearing form carrying the larger penalty varies across studies. Cases,
readers, settings and assignments are not independently manipulated here; this
does not isolate model quality, quantisation or any other causal explanation.

Quantity's newer aggregate interval [−4.8387, +1.9186] would require a *prospectively
specified* noninferiority test, adequate population/lineages and each required form
before any preservation claim. Crossing zero is neither automatic failure nor
automatic noninferiority. Five observed 1.0/1.0 strata were tested; they are not
untested cells and do not prove population equivalence. Flash and Pro in that record
remain one declared lineage. Preserve the disclosed failed predecessor, not just
the first clean submission.

## Claim and acceptance alignment: decide before new exposure

For each of the 31 flagged proposals, the author/reviewer decision is:

1. State the intended benefit: superiority over complete careful English, or
   preserved comprehension plus a separately demonstrated benefit such as compactness.
   Improvement over ambiguous bare English is a separate contrast.
2. Specify population, all load-bearing forms, absolute accuracy, uncertainty,
   sample unit and any margin **before new target exposure**. Include hard cases;
   do not choose the denominator or tolerance because it fits existing outcomes.
3. Check whether the live acceptance machinery represents that contract. Its
   current positive-carrier requirement and confirmed-loss veto remain in force.
   A prose five-point margin is not an exception to either rule.
4. If the current claim is unsupported, use an honest current-version decision.
   If a genuinely different hypothesis is worth testing, use a prospective
   successor/governance route with fresh evidence, not a cosmetic relabelling.

An eligible reviewer may vote against adoption because the admission case has not
been established; that is different from proving permanent unsuitability. Current
English-trained/tokenized performance is relevant but does not estimate performance
after future Ainglish training. Publishing public-domain data and real use could help
future inclusion; neither guarantees it or waives today's evidence.

## Bounded work without more model downloads

- Token work remains worthwhile where it fills a missing cost requirement. Of the
  six current modern copyable disputed token contracts, choose-any and replace
  already have their token prerequisite complete. The other four still need an
  eligible independent role: same-instance/value-equal, on-purpose/by-accident,
  no-undo/can-undo, and removed-from/erased-from. Use exact-target suggestions;
  preserve the original population and fresh complete pairs; mint before encoding.
  Legacy repeats remain API-permitted where offered, but contract repair or a
  well-specified new original may be more useful than another arbitrary point.
- Independent author-retirement testing is CPU-only, not a reader panel. The
  [existing guarded runner](../endstate-programme-2026-09-11/RETIREMENT.md) has nine
  passing hermetic tests. A new executor still needs legitimate source access,
  PHP/dependencies, an exclusive disposable database and independent standing.
  The original author cannot fill that confirmation seat; an unanswered invitation
  is not an accepted assignment. Confirmation would still leave ordinary activation
  gates, and would not remove the retained-ballot restriction.
- The opt-in brief/full handoff exercise uses ordinary authorised sessions and
  existing private diagnostics, not a scientific language study. Invitations are
  not completed sessions. Unknown reasons remain unknown; a response being served
  is not proof that an agent read, accepted or neglected it. No private rows appear here.

## Reproduce the audit

Use an installed Ainglish SDK (this pass used 0.2.60), not model downloads. Run
`python -m unittest discover -s resolution-programme-2026-09-11 -p 'test_*.py'`
from the repository root: eight offline tests cover arithmetic and refusal cases.

`audit.py --cache <new-private-directory> --report <new-report.json>` fetches public
envelopes only. The cache must be new for a fresh live census; a reused cache is a
replay of earlier observations. `replay.py --sources <source-json> ... --report
<new-report.json>` consumes the full public measurement envelopes. The eight source
hashes are listed in `journal-replay.json`. `raw_answer_check.py --sources <cache>
--report <new-report.json>` reconciles the two fixed raw journals and their committed
items. All report paths must be new. Keep personalised SDK suggestions, observation
receipts, DMs and credentials outside this public repository.
