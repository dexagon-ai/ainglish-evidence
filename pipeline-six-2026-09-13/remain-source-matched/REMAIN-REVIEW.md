Dexagon, 13 September 2026. No qualification or target calls had been made on
this fresh design when this review was written. This is my own design audit,
not another independent measurement or a claim of human validation.

## Scope and source limitation preserved

The original actually allocates arrival, repeat-exit, cutoff-exit and unspecified
endpoint worlds to **remain-in**, and exit, re-entry, start-exit and no-flow worlds
to **departed-from**. Each has both a mode/count and a boundary probe on different
worlds. This is not a full form-by-pattern crossing. In particular, no departed
boundary item in this component tests repeated exits or an unspecified endpoint.
Confirmation of this component cannot complete those broader prediction claims.

An initial unrun draft of this replication used a different form/probe/pattern
allocation. That would change the within-stratum population, so it was not used.
The source-matched directory is the only prospective executable packet.

The replacement contains 128 new constructed worlds, one scored item per world;
64 cases per form and 64 per probe; the exact 16 ordered form/domain strata, each
with eight items. Its domain/form/probe/pattern census equals the source exactly.
Both readers see opposite arms per world, with four of each arm per stratum.
Answer positions are balanced within each form/probe, without reading outcomes.

## Semantic review

- Each arm carries the same named scope, exact count, member type, distinctness,
  reference date, cutoff after effective changes and half-open interval.
- Ordinary singular English and member nouns agree; the registered operator is
  not silently conjugated into `remains-in`. Flow English says 'at least once'
  about each distinct member, not an event total.
- New operational totals and 09:20–10:05 event histories are generated before
  inference. Both arms share those facts. New resource rules ask for blue access
  slots versus amber history cards. This is not old inputs with renamed IDs.
- A stock report fixes blue slots only. A distinct-flow report fixes amber cards
  only. The hidden construction ledger's other total is never a reader premise.
- Boundary questions explicitly describe a **separate hypothetical individual**.
  Arrival yields stock 1; an effective cutoff exit yields stock 0; repeated exit
  ending outside yields stock 0. Unspecified interval inclusion is irrelevant to
  that separate stock-at-cutoff question and is not guessed.
- Flow boundary questions count one for a single included exit, one despite
  re-entry, one at the included start, and zero for continuous membership. They
  do not claim to test the omitted flow boundary patterns.
- The four options contain exactly one entailed answer. All 128 generated keys
  are checked against the visible statement/question, not a favourable model
  result. The structural audit separately checks uniqueness and balance; it is
  not advertised as semantic validation.

Two exact existing local model digests and source settings match. The names
`Saturnia-Sep13-*` are preserved **instrument labels**; Dexagon is the separate
measurement principal. Same host/models do not establish independent training
data or a human population. Fresh exact-configuration qualification, per-reader
run calibration, source eligibility, frozen bytes and real preregistration remain
required before target exposure. Null, adverse, floor-bound or inconclusive
outcomes will be retained. No new models or outcome-dependent replacement reader.

This is the bounded careful-English component, not the bare-left gain, full
robustness plan, future trained-model performance, or a promised ratification.
