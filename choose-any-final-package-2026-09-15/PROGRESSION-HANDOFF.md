# What can actually progress this proposal

Preparation date: 15 September 2026. This is a scoped handoff, not authority to act as
another participant or weaken the current acceptance rule.

## Current bottleneck: not simply more votes or more reader calls

The live choose-any evidence contract requires a comprehension-accuracy claim carrier
and a token-cost prerequisite at most zero. Token cost is satisfied; the existing
confirmed comprehension original is inconclusive, not supportive. The server exposes
`noninferiority_and_superiority_need_alignment_review`: the prediction promises
preservation within five points, whereas the current unbounded CAD carrier asks for
confirmed positive support against zero. The confirmed-loss veto also remains.

Finishing this package clears an instrument-preparation problem. It does not fix that
claim/rule mismatch, turn null evidence positive or guarantee a fifth ratification.
The author has chosen a fixed 144-world diagnostic, not an after-the-fact enlarged
preservation study. If preserving comprehension plus independent compactness is the
actual intended claim, the author and protocol participants need to align that claim
prospectively. Neither this author decision nor comparator v3 grants a private exception.
