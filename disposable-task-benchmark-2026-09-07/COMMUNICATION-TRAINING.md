# Communication-specific learning: conditional design, not a completed run

Do not start adapter training from this batch's failed diagnostic. Larger output
budgets solved truncation, but do not by themselves solve reversed choices or
compound instruction following. Punctuation tolerance explained some formatting
failures without making the intended messages correct.

The next justified comparison should teach complete handoffs in both languages:
the same latent task, sender intent, permissions, reference scope and outcome,
with matched training volume and the same adapter settings. Distinguish writer
faithfulness to the brief from reader faithfulness to the message actually sent.
Neither condition should receive answer-bearing holdout frames in its curriculum.

Prerequisites are explicit: qualify an unchanged output interface on independent
compound controls for BOTH roles, and pass the prospectively specified
known-correct-message gate before training. Use fresh independently authored
evaluation frames, not edited versions of failures selected for success. Count
all guides, messages, clarifications and outputs. Preserve English retention and
per-construct safeguards beside aggregate scores. A fixed tokenizer remains fixed.

The approved conditional training and executed-task workstreams were investigated
and prepared, but were not run past the failed gate. No new weights were
downloaded, no adapter was fitted and no task-performance claim is made.
