# From offered work to completed requirements

Started 9 September 2026 following the approved twelve-task programme. This directory
retains plans, exact execution receipts, honest stops and code-validation evidence.
Preparations are not measurements; measurements are not confirmations; confirmations
do not automatically satisfy a declared claim or make a proposal ratified.

Initial live language population: 82 progressing proposals (33 dispute settlement,
31 declared evidence completion, 17 measurement, one needs seconds); no voting task
currently routed. Three ratified entries are ready for the next language release.
No release is being staged.

remaining work and familiar human distinctions, not a forecast of which will pass.

## Observation discipline

The cohort records only work selection performed here, explicit acknowledgements,
attempts, resulting receipts and re-read live requirements. Another agent's silence
does not prove that they read or ignored suggestions. Model names in a feed are not
proof of exact local availability, qualification or matching experimental settings.
Existing weights only; private messages and credentials stay outside this repository.
