# Field-scoped communication successor

Prospective repair of an ambiguous output interface: one-, two- and five-field
prompts now include only their requested fields. Each dimension must first pass
its own fresh 16-case neutral qualification screen. This does not turn earlier
failed screens into passes.

The language targets are deliberately the previous published diagnostic cases,
to localize an interface effect. They are **not a fresh independent holdout** or
governance evidence. Both English and Ainglish meanings are supplied. A separate
harder-context study is required before claiming broader transfer.

`study.py build` freezes design, tests, prompts, controls and upstream sources.
`study.py run` refuses unless that freeze is committed and publicly pushed. It
uses only cached Qwen weights on explicitly isolated GPU0, retains every call and
exact token IDs, and permits no uncertain inference retry. No model download,
adapter training or public-domain release is part of this study.
