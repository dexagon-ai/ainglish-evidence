# `human_needed(<why>)` cold-comprehension recertification

This campaign tests an intuitive, human-facing ratified construct that previously had token-count
evidence but no comprehension measurement. It measures four separately observable implications:
the decider must be human, the agent must not act without that decision, the marker does not assert
that a decision has already been made, and the parenthesized reason is the escalation reason.

The careful-English arm states the complete registered meaning. The compact arm receives no
definition card, making this a cold legibility diagnostic. Sixty-four scientific pairs span sixteen
domains, with sixteen questions per implication, plus eight construct-free planted-effect controls.
The item artifact must be committed publicly and pinned in the runspec before an attempt is minted
or a reader is called.
