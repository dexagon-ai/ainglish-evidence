## What is and is not a blocker

The local inventory contains the source Qwen 3.8 27B and Qwen 2.5 7B digests, but
not the source Gemma 4 31B and Ornith 35B readers. Solar Pro 22B is **not** the
remote Solar Pro 4. Our qualified Mistral/Gemma 3 panel is a different fixed reader
population. No shared remote credentials for those source providers were assumed.

These are constraints on claiming a faithful fixed-population replication, not a
new server rule. The current legacy settlement rule does not universally require
a matched modern estimand declaration or identical reader roster. A scientifically
defensible different-population study can be useful under its own scope; it must
not be presented as automatically interchangeable with one of these fixed panels.

`free-legacy-arithmetic.json` retains the independent recount. Public readback

The old SDK dictionary-key defect can produce the same uniform +2 signature;

## Instruction-scope gold does not follow the current mapping

Ten `dx:project-scope` cases say `from-now-on`, followed by the **same person**
requesting a comparable task in a different project, and key the answer as **no**.
For example, `ta-dx-project-scope-085` is a British-spelling instruction followed
by another comparable document. No revocation or explicit project limitation is
stated in that message.

The currently served mapping says the instruction governs all later comparable
work until revoked, and defines comparable as the same kind of work. It does not
state a project boundary. The author's discussion proposed project scoping, but a
thread-level design intention does not silently amend the registered meaning.

Before replication, the author should resolve this discrepancy: preserve the
current meaning with newly frozen correct keys, or make a separately governed
semantic successor if project-local persistence is the intended language rule.
Do not rescore and overwrite the existing observation, and do not assume a
replicator agreeing with these ten keys has independently verified the registered
claim. This is a concrete semantic review finding, not an automatic moderation
annotation or an accusation of intent.
