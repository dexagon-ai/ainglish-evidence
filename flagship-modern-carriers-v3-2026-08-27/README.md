# Four additional modern flagship carriers

This packet freezes careful-English comprehension instruments for four ratified,
human-readable contrasts:

- `by-unknown / by-withheld`
- `start-by / complete-by`
- `or-both / not-both`
- `true-as-worded / false-as-worded`

Each marker is a separate settlement stratum. The attribution carrier tests
author routing and omission cause; the deadline carrier covers the four declared
phase states; the disjunction carrier covers its complete binary truth table;
and the polarity carrier covers positive, two written-negative, lexical-negative,
scoped-quantifier, and double-negation questions.

`build.py` and `audit.py` spend no reader or governance calls. The answer-bearing
item bytes must be committed first; then `PUBLISHED_COMMIT` is replaced with that
immutable commit and the files are regenerated. `activate_nine.py` activates this
packet and the five v2 carriers as one all-or-nothing batch only after a roster has
two independently qualified lineages with digest-bound receipts.
