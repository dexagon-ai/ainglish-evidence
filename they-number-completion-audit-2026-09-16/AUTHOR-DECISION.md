## Proposed complete coverage, if that decision permits a study

The original contract's minimum 120 items is a floor, not a power calculation. Freeze a finite
population and sample size appropriate to the chosen confidence statements before target calls.

| Component | Required design property | Kept separate in the result |
| --- | --- | --- |
| Main reader comparison | Both number forms; shared operational context; meaning-equivalent marked and verbatim per-form English; held-out next-action question, not “one or many?” | Per-form absolute accuracy, difference and uncertainty; pooled summary cannot cancel a failed form |
| Bare wording | Same declared semantic worlds, but arm-specific correct unknown when text is insufficient | Correct uncertainty, safe actionable resolution and unsafe-action rates; no fabricated same-gold superiority |
| Both-readings-live admission | Blinded agent reviews see only the bare message first; verdicts frozen before intended form/gold is revealed | Exclusions, reasons and surviving count; no human-reviewer campaign and no selecting items after reader answers |
| Ontology | Ledger distinguishes referent entities from represented people; committee-as-one and multiple-entities boundary cases | Quorum/headcount answers only when extra context genuinely licenses them |
| Five nonclaims | Gender, known identity, unanimity, all-members participation, collective action; both forms where relevant | Each error rate and denominator, with an uncertainty bound; never only a pooled boundary score |
| Cost | The same final frozen paired population and exact English rendering | Every registered tokenizer and each form; least-favourable aggregate; no new tokenizer/model download assumed |
| Exposure | Cold condition fixed in advance; no target-bearing calibration or answers in the reader context | Any later entry-informed experiment gets its own preregistered question, not a post-hoc rescue |

For scale only, zero errors in 59 independent trials gives a one-sided exact 95% upper bound below
5%; zero errors in a tiny audit does not. That is a single-endpoint illustration, **not** a sample
size justification for ten form-by-nonclaim endpoints, clustered worlds or multiple readers.
The full design needs its own declared unit of inference and simultaneous-claim policy. Repeated
templates, name swaps and several questions about one world do not create independent worlds.

## Concrete semantic witness (unrun, not an evidence item)

A shared workflow rule sends the job to workflow K when the number of responsible registered
entities permits one sign-off, and workflow M when distinct responsible entities each require a
sign-off. A context must explicitly say how represented people, delegated signatures and
committee-as-one treatment affect that rule.

The question asks which workflow is warranted, with “request clarification” available. The
marked and careful-English forms can warrant the same K/M decision; bare “they” can correctly
warrant clarification. Count improved information availability without pretending that the
clarification answer was a reading mistake.

Use many genuinely different operational consequences and counterbalance action labels and
per-form answer distributions. This witness does not prove that a full bank is free of shortcuts.
