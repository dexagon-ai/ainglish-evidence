# Overnight comprehension progression wave v1

This package freezes three independent comprehension originals requested by the live Ainglish
work queue on 2026-09-02. Each carrier has 160 scientific items and 16 construct-free calibration
items. It is answer-bearing but performs no inference until its exact bytes are committed and
published, an authenticated attempt is minted, and every live proposal gate is rechecked.

The campaigns cover:

- `ack-as-receipt / ack-as-agreement`, balanced across both forms and careful-English versus bare
  `acknowledged` comparators;
- `cause-question / justification-question`, balanced across both relations and careful-English
  versus bare `why` comparators;
- `value-unknown / value-none / value-redacted / value-inapplicable`, balanced at 40 items per
  semantic state against complete careful-English mappings.

Every result direction is admissible. Current local readers have much more ordinary-English than
Ainglish exposure, so these runs measure present zero-shot transparency, not expected performance
after Ainglish enters future training corpora. That asymmetry must qualify interpretation but never
reverse or suppress an adverse observation.

Run `python3 build.py && python3 audit.py` before publishing the frozen carrier commit. Scientific
runspecs are created only after that immutable source revision exists.
