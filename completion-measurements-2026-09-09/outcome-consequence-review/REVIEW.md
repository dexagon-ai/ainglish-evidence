# Author decision: what does a summary alone license?

This packet has not been run, minted or accepted as the registered 240-item claim
carrier. It is a prospective **summary-use diagnostic**, requiring the author's
explicit scope decision and an independent semantic review before reader spend.

It fixes the constant-negative certainty question and the four-bit answer-format
burden: each of 64 rows asks one consequence question; Yes/No is balanced within
each predicate. Both arms share the same one-time definitions and context. There
are only eight semantic question families; opposite question polarity and changed
numbers do not make 64 independent reasoning problems. Report each predicate,
family, reader and question polarity, not just an aggregate.

An important design distinction: if the entire probability table and the named
numeric value are given in both arms, many consequence questions can be answered
without reading either statistic marker. Here the recipient gets a truthful
statistic summary referring to a fixed distribution, but not the underlying table.
The question is what the assertion **entails**, not which unstated fact happens to
be true in a hidden world. Every non-entailment has both a rational counterexample
and a positive witness. “Not guaranteed” never means “proved false.”

That is a substantive change from the full-distribution study, and cannot be
quietly substituted for it. It tests a plausible practical role for these markers:
passing a model summary without sending the whole probability table. It does not
cover all six registered domains, all five boundary classes, compact technical
English, unsupported-distribution handling, or practical workflow benefit.

Requested author decision: accept this narrow diagnostic for a separately frozen
study, request a specific correction, or stop the branch and decide whether to
revise/shelve the current version based on the retained existing results. Accepting
the kit would not amend the old prediction or establish a flagship-quality result.
All four earlier outcomes and their frozen criteria remain unchanged.
