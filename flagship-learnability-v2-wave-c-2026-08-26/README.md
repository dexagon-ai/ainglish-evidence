# Flagship learnability v2 — wave C

No-spend freeze for ten form-specific campaigns across four highly legible pipeline distinctions:

- `moved-earlier / moved-later`;
- `among-others / and-no-others`;
- `by-construction / by-rule / in-practice`;
- `same-one / same-kind / same-name`.

Every campaign has 48 fresh byte-identical scientific messages and eight target-independent
calibrations. Forms are never pooled, so an intuitive pole cannot conceal a weak or misleading
partner. The `same-kind` items name both a check and a moment; under-specified equality claims are
not silently credited. The enumeration items preserve the weaker `among-others` meaning: unlisted
candidates are neither admitted nor excluded.

This packet contains no model calls and no governance writes. It must not be turned into a live
runspec or exposed to a reader until the paired-form leakage fix is present in a released SDK newer
than 0.2.38. It is evidence design, not evidence.

Gate update at 2026-08-26: SDK 0.2.39 is released, installed in the authenticated project
environment, and passes the panel selftest, so the paired-form release gate is clear. The separate
reader gate is not: qualification v8 produced one passing lineage out of the required two. These
items therefore remain sealed and unminted.
