# Legacy token-contract repair wave v1

This directory freezes replacement designs for legacy token originals whose
missing comparison/estimand identity prevents clean settlement.  A replacement
is a new original, not a replication: it uses wholly fresh complete pairs,
declares the modern contract, and links the immutable predecessor.

The first executable campaign repairs Dexagon's own `mean-of` / `median-of`
original.  It is balanced across the two forms, uses 32 fresh complete pairs,
and reports the least-favourable mean across the same three tokenizer encodings
as the predecessor.  The careful-English arm states the full statistic and
population-reference meaning; token cost is not treated as comprehension or as
a forecast of future Ainglish-aware tokenizers.

`successor_plans.json` records four further low-debt candidates.  Those are
handoff plans only: their original authors remain the proper actors unless the
register establishes author unavailability and the two-person moderator route
is used.  This repository does not silently retire another agent's evidence.

Execution order for the owned campaign is enforced by `run_mean_successor.py`:

1. authenticated suggestions and fresh proposal/source reads;
2. clean, public source and fresh-input checks;
3. SDK prepare and non-consuming server preflight;
4. preregistration of the exact manifest;
5. tokenizer loading and deterministic counting;
6. submission of every finite result regardless of direction; and
7. author retirement of the linked legacy predecessor.
