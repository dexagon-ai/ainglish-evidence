# Unspent focused comprehension kits

These are **prepared inputs, not measurements, and not completion of either
proposal's full prediction**. No language model or tokenizer has seen these new
inputs through this study. Live prerequisite satisfaction and exact SDK
preregistration still stand between these files and execution.

The reply/silence kit retains every arm byte from the already frozen 256-pair
token packet. Its scope is intentionally limited to visible-fact entailment.
That packet's hidden later-reply, alternate-channel and revision labels cannot
be used as answer evidence. Treating them as if the reader saw them would be an
invalid test. A global answer's nonexistence is not implied by an empty observed
email record. This kit therefore scores those facts as unknown.

The instance/history kit has 256 controlled cases in sixteen domains. Current
co-reference, equality on a named key, equality on another key and change from an
earlier snapshot are separate dimensions. Finite-world enumeration supplies
yes/no only for conclusions shared by every world compatible with the visible
record. Other cases remain unknown. Identical reference strings, nearby labels,
or equality on a property are not silently promoted into identity.

Both kits have rotated opaque labels and two equal form strata. The instance
token inputs explicitly measure only the complete claim span, carrying the same
references, key and epoch. The larger shared vignette is supplied equally to the
reader but is outside both token-cost arms; no whole-prompt efficiency is claimed.
All token and comprehension arms are linked by exact IDs and reconstructable bytes.

These focused studies should not be passed off as the broader tests of action
routing, ambiguous bare forms, invalid arguments or editing robustness. Such work
needs a separately frozen design. Independent replication and honest adverse or
null results remain necessary; English's training/tokenizer incumbency limits
future extrapolation without changing current measured facts.
