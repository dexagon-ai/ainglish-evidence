## What changed

All 201 v2 prompt objects are preserved exactly; the accepted candidate digest,
question meanings and old golds are unchanged. Five additional partial-record
worlds cover the previously missing form/dimension endpoints. Each has three
option rotations and gold **Not established by the record**. Totals are now
60 worlds, 72 question probes and 216 variants, not 216 independent observations.

The singular person controls cannot literally copy the plural quantifier gap:
their available profile/identity-check fragments establish some background facts
without establishing the queried gender or recorder knowledge. The singular
ensemble records one coordinated segment, not coordination of the full rehearsal.
The plural committee/team cases omit one member's vote or task participation.
These are proposed semantic controls needing independent review, not validated
representative samples. Like v2's explicit uncertainty cues, they test respect for
stated limits of a record, not suppression of every spontaneous inference.

Each of the ten endpoints now has executable, separately reported **synthetic
fixture checks** for explicit facts and partial evidence. Each uses the frozen
9/10 observed-correct floor; incomplete responses or absent coverage cannot pass.
With three partial variants per endpoint, all three must be correct. No rotations
are treated as independent samples and no confidence bound is claimed. These
checks are proposed review-fixture behavior, not a new scientific admission rule.
Only these two named checks contribute to `fixture_acceptance`. The other coverage
families remain separately reported, not given new thresholds by this bounded
repair. A pass does not assert that every cue/nonclaim answer was correct; a future
instrument would need its own fully reviewed acceptance contract.

The oracle-except-partial Yes and No witnesses now fail all ten endpoints while
passing every explicit-fact check. A fully answered wrong response set is complete
but fails. Missing/null answers remain incomplete, not incorrect. The oracle can
pass the fixture checks, but `instrument_qualified` and `fileable_measurement`
remain false. Known constant-label/position and question-blind witnesses also fail.

The unconditional `complete_is_not_passed` slogan is replaced by an actual separate
`fixture_acceptance` result. The observation schema is still exactly one response
per prompt: **replica_index is unsupported and rejected**. This is not a repeated-
read implementation; future repeated reads need a separately reviewed contract.
