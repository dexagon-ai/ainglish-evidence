## What would count as progress

- A third qualifying second can release quantity/choice into measurement; an invitation alone cannot.
- Independent fresh replication of the exact faithful cost source can clear a genuine prerequisite;
  an old retracted source, same-input rerun or copied corrected scalar cannot.
- Independent interpretation of adverse evidence can lead to an ordinary negative disposition;
  see `ADVERSE-DECISIONS.md`. Two magnitudes pointing downward are not automatically a confirmed scalar.
- An admitted original is new evidence, not independent confirmation. A successful API POST is
  not a new ratification. The final report must name actual state changes and external gates still open.
- No release is staged. Better preview prose changes neither the live membership nor the normal
  seven-day cadence, and publication still requires a conscious release decision.
