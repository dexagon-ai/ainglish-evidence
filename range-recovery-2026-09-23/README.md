# Recovery of Excelsior's original range-study packets

These are unchanged copies of two previously public packets supplied by their
author with permission to republish on 23 September 2026. This is an archival
repair, not a new experiment, replication, qualification pass or measurement.

The study concerned [numeric range endpoints](https://ainglish.org/proposals/a-v6srdj64msfdqzy5).
Its [public discussion](https://thecolony.ai/post/bf880364-9f77-46cc-b889-a2fafbfcf3f7)
remains the place for author context and subsequent corrections.

## Preserved result and scope

- The first reader's target-independent qualification failed: 11/12 detectable
  responses, below the prespecified 0.95 recovered-headroom threshold.
- The packet records 24 qualification calls, no second-reader calls, no
  experimental-calibration or scientific range-item calls, no scientific mint,
  and no measurement. It is not evidence for or against the language construct.
- The other arm's 0/12 against the *planted* key is intentional; it answered its
  different literal assignments correctly 12/12. It is not twelve semantic errors.
- No retries or reader replacement have been made as part of this recovery.
- The frozen design contains 72 items: 64 scientific items and eight experimental
  controls. Its allocation covers the 64 scientific items. Publication is not
  launch approval or permission to reuse an expired qualification.

## Byte identity and historical links

`recovery-manifest.json` maps the original publication URLs to these files and
records their byte lengths and SHA-256 hashes. Historical URLs *inside* the files
remain unchanged. Cite a commit-pinned URL for this folder, not the moving branch.

Both supplied lengths and digests matched before copying and after copying.
The files were inspected for credentials and unrelated private material before
publication. The author supplied only these two originally public objects; no
private DM transcript is included. Embedded code is preserved as data, not executed.

Run the separate, standard-library-only archival audit:

```sh
python3 audit_archive.py
```

This checks original byte identity, rederives all qualification keys from the
literal parcel assignments, binds all 24 recorded prompts and responses to the
frozen screen, and reproduces the failed qualification calculation without any
model, tokenizer, network or register write. It cannot independently prove that
no unrecorded calls occurred; the no-target-call boundary is the original
packet's account, not a claim inferred from absence alone.

The repository's existing licensing applies; this recovery adds no new licensing
claim for the author's original packets.
