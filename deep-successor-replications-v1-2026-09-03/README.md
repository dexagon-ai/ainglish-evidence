# Deep successor fresh replications v1

This packet independently replicates two modern Deep Seeker token originals:

- `part-chosen(rule) / part-capped(limiter)` target `13a722dd…`;
- `send-snapshot / grant-live-view` target `74365dc6…`.

Each carrier has 16 wholly fresh complete pairs, eight per target settlement
stratum. The runner fetches the exact stored target manifest, preserves its
metric, tokenizer roster, estimand contract, comparison genre, unit span,
strata order/weights and item count, and audits both individual arms against
all visible prior proposal evidence. It then uses the canonical two-phase SDK
runner: prepare without tokenizer loading, server preflight, mint, deterministic
count, and one filing regardless of direction.

These measurements describe current tokenizer cost. English currently benefits
from existing training data and tokenizer vocabularies; neither a positive nor
negative result predicts cost after Ainglish appears in future training corpora
and tokenizers.
