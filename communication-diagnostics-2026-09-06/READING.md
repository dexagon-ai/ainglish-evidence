# Where did the communication interface fail?

The frozen diagnostic completed 612 target calls and 16 control calls. Every call
ended within its fixed output budget; input and generated token IDs are retained.
Both initial role screens passed 8/8. This does **not** establish that the harder
five-field task was a qualified instrument for communication-adapter training.

The predeclared training gate failed. Correctly authored five-field messages were
interpreted exactly in 44/96 Ainglish cases and 58/96 English cases, below the 80%
floor for each arm. Only 2/96 Ainglish and 43/96 English writer outputs matched the
requested fixed-line interface, also below its separate 80% gate. Adapter training
and a downstream executed-task claim are therefore held, not silently attempted
under this failed instrument.

## Format is not the same thing as meaning

The one-field condition scored 0/6 in both languages under the frozen exact-key
JSON protocol. The raw responses often answered all five fields from the guide,
not just the requested field. Do not read this as evidence that the model failed
to understand inclusion six times. The two-field condition scored 12/12 Ainglish
and 9/12 English. Those small results use only three authored contexts.

The writer frequently appended colons to the prescribed lines. The frozen parser
rejects those as **unparsed**, not as proven semantic errors. `format_audit.py`
reports a separately labelled post-hoc punctuation sensitivity check, without
correcting choices or changing the original scores. Genuine reversed choices
also appear: punctuation is not the only problem.

In that post-hoc audit, removing only terminal colons/periods makes all 96 writer
outputs per arm parsable, but only 34/96 Ainglish and 53/96 English messages match
the intended five choices. All six one-field outputs per arm contain the correct
requested inclusion value plus extra keys. These clarifications explain the
strict failures; they do not alter the failed prospective training gate.

The guides define both languages and the writer uses a fixed phrase table. This
is a constrained, reference-assisted interface, **not unaided reading, unrestricted
prose, independent agents, human validation, or governance evidence**. It narrows
the previous free-prose failure rather than replacing it. There are three authored
contexts, not 114 independent reasoning templates.

## What follows from it?

A future instrument should qualify target-independent controls at its actual
compound output complexity, avoid showing irrelevant output keys, and separate
format compliance from meaning. Any changed prompt or parser needs a new frozen
plan and untouched targets. Repeatedly trying this holdout until it passes would
not repair the original result. Training on the measured failures would also
make these cases training material, no longer an untouched holdout.
