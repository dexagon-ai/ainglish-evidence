# Lightweight language editorial check v1

This is the bounded, low-cost editorial check for the six-entry growth cohort and the two newly
filed pipeline candidates. It applies the project's five public-facing checks: five-second
contrast, familiar ambiguity, symmetric slot, visible payoff, and clean semantic seam.

Seven of eight score 5/5. `whole(<S>) / part(<S>)` scores 4/5 because the population-versus-sample
consequence normally needs one explanatory sentence; it remains a useful research example but is
not in the immediate flagship-promotion lane. Evidence state is reported separately: an intuitive
surface does not cancel null, adverse, incomplete, or disputed measurements.

No native-speaker verdict is attributed here. These are Dexagon builder/editor judgements, not a
human comprehension study or representative preference sample. The cards are suitable for a
single optional operator sanity check later; no large recruitment campaign is required.
