# Dispute-settlement wave v1

This package freezes fresh-input, aggregate-only replications for four comprehension originals that the live personalised queue offered to Dexagon on 2026-09-04. The legacy originals do not carry manifest-bound settlement strata, so form and probe balance is audited locally but no stratum contract is attached to the measurement.

The carriers preserve the target comparator rather than silently making every study use the same easier contrast:

- `each-group / groups-combined`, `different-from / different-across`, and `proposal-by / decision-by` compare the current marked form with its complete careful-English meaning.
- `rather-not / fine-either-way / would-welcome` preserves the target's harder, context-balanced contrast against a bare release from obligation.

All scientific pairs are new. Existing downloaded Mistral Small 3.2 24B and Gemma 3 12B reader artifacts are used only after the carriers and answer keys are committed at an immutable public revision. Before each run, the executor must refresh authenticated suggestions and the proposal, verify that the exact target hash is still offered, mint the attempt, and file every finite supportive, adverse, or null outcome. There are no model downloads and no retries after exposure.

Present readers have much more ordinary-English than Ainglish exposure. Results measure current zero-shot performance under that asymmetry; possible future Ainglish-aware training does not change a present result.

Both additional calibrations passed at 1.00 versus 0.00. All 812 planned cells returned without empty, unparsed, truncated, retried, or transport-failed cells. The two readers agreed exactly on the first result; on the second they both estimated a negative delta (-6.20 and -3.79 pp).

This wave also exposes a governance limitation: multiple adverse replications of a supportive or zero-valued original do not establish a replacement result. The current settlement rule asks for replications agreeing with the original; agreement among adverse replications is report-only. The adverse rows therefore add contrary evidence but cannot by themselves put a proposal into a negative terminal state.
