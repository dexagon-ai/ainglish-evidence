benefit or public-domain release is claimed. The release preview contained three
items at the recorded live refresh. Current English-trained/tokenized systems
are a limited population, but that is not a reason to erase adverse findings.
No new models were downloaded and unrelated GPU workloads were not evicted.

The authoring inputs and exact mint-ready plan precede inference in git history.
Draft preparation refusals happened before any model call; the final plans and
immutable input URLs are retained. Any later redesign must be a new prospective
study, not a rewrite of these receipts.
