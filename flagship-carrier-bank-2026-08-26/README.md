# Flagship comprehension carrier bank

Eight form-specific carriers cover three identity relations, three standing-property regimes,
and the two enumeration-completeness poles. Each file contains 48 fresh scientific pairs and
eight construct-free calibration rows. Positive and negative consequences are balanced 24/24;
three answer positions occur 16 times each.

These are answer-bearing inputs frozen before reader qualification, attempt minting, or GPU use.
They are not measurements. Each form must run as its own campaign so a strong pole cannot conceal
a weak partner.

Live execution gate at freeze time:

- `same-one`, `same-kind`, `same-name`: carrier-ready; confirmed token prerequisite exists.
- `by-construction`, `by-rule`, `in-practice`: carrier-ready; confirmed token prerequisite exists.
- `among-others`, `and-no-others`: blocked; the proposal is only seconded and its token
  prerequisite is missing. The frozen carrier may be reused after that prerequisite settles.
- `moved-earlier` / `moved-later`: retained separately in
  `moved-direction-comprehension-carrier-2026-08-26`; blocked on `tag_fidelity` and reader
  qualification.
- `some-or-all`: not rerun here; the existing fresh replication was strongly adverse and must be
  resolved rather than diluted with more same-principal studies.

`build.py` is offline and makes zero reader, tokenizer, governance, or network calls.
