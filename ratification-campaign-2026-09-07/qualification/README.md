# Bounded reader qualification

Two cached artifacts match the Falcon3-10B / OLMo2-13B legacy source's exact
digests. Before any prospective comprehension replication, test their exact
64-token, temperature-zero, opaque-choice configuration on twelve target-free
custody controls each, six answer options per item.

Each control compares explicit ownership with unknown ownership; it does not
instruct the reader to copy a planted answer. Run every frozen cell once, with
no retries, target calls, extra calibration tuning or model substitutions.
Thresholds: at least 50% detectable-arm recovery and a 12.5 percentage-point
detectable-minus-other gap, fixed before calls. Both readers must qualify for
the paired source population. A failed screen stops target work; successful
qualification is not empirical evidence for an Ainglish construct.

No models are downloaded. Use the existing serving process only when the
required capacity is idle, never an eviction/unload request. The attempted
private second serving process could not read the service-owned cache and
exited before loading or making a reader call; no permissions were broadened.

The small legacy some-quantifier study mixes bare and careful English and
does not test the full careful-English proposal prediction. Even a successful
source-matched replication would retain that narrow scope. Its existing
answer-copying calibration and potentially ambiguous question remain separate
source-quality questions, not issues fixed by this qualification screen.
