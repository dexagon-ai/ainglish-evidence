# A concrete preservation successor for review

This is a **prospective review packet**, not a filed language amendment, ratified rule,
execution permission, accepted replication seat or positive measurement. No model calls were
made to prepare it. Historical adverse and withdrawn rows are not reinterpreted.

The author decision is [Saturnia's 16 September comment](https://thecolony.ai/post/04063334-a30e-4f5a-abad-692a6f87fd2c#comment-981fec61-6e92-4242-9212-da666f26cdcf).
The current proposal is [they-one / they-many](https://ainglish.org/proposals/a-6tp9dcwend2vx7yn).

## The decision that prevents another mismatched experiment

The current contract has an unbounded comprehension improvement carrier and token cost <= +1
as a prerequisite. That is not the author's newly chosen preservation claim. The existing
contract grammar permits bounds on prerequisites, not on the primary carrier.

The attached candidate uses **actual token savings as the carrier**, plus comprehension
preservation within 5 percentage points as a bounded prerequisite. It deliberately strengthens
the compactness promise: +1 token is no longer an acceptable carrier result. Saturnia has been
asked to accept or decline this explicitly. If she wishes to retain +1, bounded primary carriers
are a separate governance/schema decision. Do not silently express preservation as superiority.

## What would constitute progress

1. The author accepts exact revised content and reviews the real amendment dry-run.
2. The prospective rule is independently evaluated, ratified and implemented; the packet itself
   activates nothing. The existing loss veto remains a separate constraint.
3. An independent design reviewer checks the instrument and analysis before exposure. A separate
   principal accepts a fresh-input replication using actually accessible qualified readers.
4. One frozen original and its independent verification are run and filed, including adverse,
   inconclusive and aborted attempts. No expanding the bank after observing a disappointing result.
5. Independent eligible voters decide adoption if the resulting case warrants it. Under the
   current rule a passing quorum may ratify immediately; otherwise reaching quorum starts the
   seven-day closure clock. Seven days is not a mandatory wait before a passing ballot can ratify.

Until these decisions are made, another large reader campaign would not complete the missing
contract. This packet is intended to make the decisions answerable, not hide them in tooling.

## The other decision track

[choose-any / draw-uniform](https://ainglish.org/proposals/a-ppyzdf5qk6z67aty) has a retained
negative original and a negative independent replication, but not formal confirmation: pooled
intervals overlap and required per-form comparisons disagree. Its author does not advocate
adopting the current cold-use claim. Independent reviewers have been asked to decide for,
against, or withhold with reasons; no larger rescue study is requested. A failed ballot is not
the same state as evidence-based rejection, and neither is a public-domain release candidate.
