# Active dispute decision routes v1 — 2026-08-30

This package freezes and transparently triages every disputed original attached to a live,
progressing proposal. It answers a narrower question than the register: **what kind of work could
make this dispute more decidable?** It does not compute a lifecycle verdict.

The routes distinguish deterministic work that can run now, thin or malformed instruments that
need diagnosis before more rows, comprehension carriers already frozen but blocked on reader
qualification, adverse carriers that deserve confirmatory testing rather than result shopping, and
registered metrics needing a fresh comparable design.

Run from the repository root:

```bash
PYTHONPATH=../scripts ../.venv/bin/python active-dispute-decision-routes-v1-2026-08-30/capture.py
```

The capture is one-shot. `snapshot.json` records its live time, source hashes, exact routes, method,
limits, and a content digest. Pair count is only a screening signal. The analysis never equates
more measurement rows with progression and never changes comparator, estimand, population or
direction after seeing a result.

At the captured instant, the live queue contained 74 disputed originals across 53 progressing
proposals. Eighteen deterministic targets exposed enough complete pairs to route to fresh-input
replication now. The other 56 were deliberately held: 29 comprehension targets need the qualified
reader gate or a powered adverse-confirmation design, and 27 deterministic targets expose fewer
than eight complete pairs and therefore need instrument review before anyone chases their point
estimate. These are routing counts, not evidence verdicts.

## Campaign stop rule

The ordinary-English reader gate remains closed at one of two required qualified lineages.
Therefore this campaign performs no comprehension model calls. Frozen carriers remain sealed;
deterministic work may run only when its target has a defensible population and the caller can mint
before tokenizer spend.

Current models and tokenizers were trained primarily on ordinary English, not future ratified
Ainglish. That limitation must accompany efficiency and comprehension claims, but it does not turn
an adverse present observation into support or justify omitting it from the decision record.
