Apply `no-undo-repair.patch` in a disposable checkout at that exact base, then run
`python test_noundo_repair.py /path/to/patched/no-undo-rstar-2026-09-22`.

The patch rejects empty/malformed recovery fields, delimiter-bearing actions,
case-insensitive forbidden holder/path prefixes and terminal action punctuation.
The token headline is explicitly the maximum tokenizer mean, not the roster mean.
The frozen joint profile includes category, speech-act label, action/path/holder
lengths and exact cost/window values. Equal marginal category counts alone do not
establish equal sampling. Report/instruction labels and complete restoration
meaning still need semantic review; passing the parser is not that review.

## Calendar: why no bank or inference yet

`calendar_capacity.py` enumerates 1,753,164 feasible date relations for anchors
2100–2499. Epochs are exclusive, in this priority: different year; interval contains
29 February; different month; ordinary. The 84 cells can meet three cases per epoch
in each 12-case cell. This is an allocation feasibility result, not a frozen sample.

Under the stated IID paired-outcome sensitivity model, 504 independent pairs at
a true 30-point gain have only about **35%** probability of clearing a conservative
20-point lower-bound target. That becomes nearly 100% at a true 40-point gain.
For a control rate of 2%, 120 items have only **30.5%** probability of certifying
an upper bound below 5% with the stated one-sided marginal rule; tightening alpha
from .05 to .005 reduces it to **8.85%**. These are design assumptions, not observed
reader behavior or the official CAD inference method.

Arms and repeated readers are not additional independent worlds. The proposed
17,028-call three-reader budget from the earlier design is **not approved** by
these calculations. Neither is a new minimum useful budget established. Saturnia's
HOLD remains: a bare-comparator gain and careful-English preservation cannot
silently satisfy a strict-positive careful-English contract.

## it(ref): what the draft actually covers

`itref-inputs.json` contains 684 review items: 192 primary worlds (96 paired-intent
frames), 216 validity controls, 216 nonclaim controls, 48 corruption cases and 12
single-antecedent checks. Full, unambiguous repeated-noun English is a separate
arm from the deliberately ambiguous bare-pronoun diagnostic. Keys are in a
separate file; do not include that file in model prompts.

Valid-to-valid reference replacement is correctly read as the **received** other
referent but also flagged as a transmission error against original sender intent.
It is not evidence that the notation detects corruption. When only marked syntax
is broken, the intact noun arm retains its own correct key; it is not falsely
scored as invalid too.

This export implies 1,356 calls per reader if all arms were eventually approved;
none were run. **The complete promised instrument is not finished**: definition-
conditioned learning, summarization and translation need separately reviewed
instruments; target-independent controls, reader roster/qualification, absolute
floor, official harness conversion and joint analysis are not fixed. The current
claim/carrier mismatch also needs an explicit prospective decision. Independent
review of these templates cannot be inferred from acceptance of the narrower
proposal scope. The file's `critical_unfinished` list is normative for this packet.

The request-journal audit treats an issued request without a retained terminal
receipt as uncertain exposure, never an automatic retry opportunity. It retains
null/adverse completions and transport failures equally. It cannot certify that a
