# Flagship comprehension originals

Eight form-specific campaigns cover the four highest-ranked, current ratified examples in the
website's editorial flagship catalogue. Every campaign compares one marker with its complete
registered careful-English meaning over 100 fresh pairs, uses held-out consequences and the SDK's
`opaque-choice-v1` answer binding, binds two local reader editions, calibrates before scientific
spend, and preregisters exact retained manifest bytes before any model call.

The campaigns are deliberately separate: weakness in one half of a pair cannot be hidden by the
other half. Each is an original only. A supportive result cannot become confirmed until a distinct
principal runs a genuinely fresh, different-input replication. Null, adverse, calibration-failed,
and instrument-failed outcomes are retained without retry.

Freeze order:

1. Run `build_items.py`; inspect, commit, and push the eight answer-bearing files.
2. Run `build_runspecs.py --items-commit <full-public-commit>`; inspect, commit, and push the exact
   runspecs and index.
3. Confirm the dedicated reader and GPU gate, then run `run_all_once.py` exactly once.
4. Commit the finite result/abort receipts and publish all outcomes before seeking replications.

The generator makes zero reader or governance calls. The live runner starts each work selection
with authenticated suggestions, freshly reads the chosen proposal, then uses the SDK's atomic
mint-before-spend path.

The preregistered standalone non-inferiority margin was -5 percentage points. Only the saturated
`we-including-you` tie clears that margin; it still does not provide the positive effect required
for supportive comprehension evidence. None of these originals is therefore presented as a
supportive flagship-qualification result, and no confirmation was requested merely because a run
completed.

This is a cold, standalone marker-reading test with two local model families, not human validation
and not an instruction-conditioned test after loading the register reference. It answers the
narrow question actually preregistered: whether the compact form by itself preserves held-out
consequences as well as its complete careful-English mapping for these readers. The severe
`one-hop-delegation-allowed` result is useful adverse evidence for that claim, not a reason to
discard or redesign the frozen items after seeing the outcome. A future, separately preregistered
study may measure reference-loaded comprehension, but it would estimate a different deployment
condition and must not overwrite this result.
