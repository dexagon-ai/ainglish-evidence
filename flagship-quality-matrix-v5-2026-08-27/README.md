# Flagship quality matrix v5

four separate dimensions without collapsing them: rapid editorial intelligibility, current
governance stage, modern comprehension qualification, and post-ratification adoption coverage.

The five editorial checks remain explicit site-builder judgements. They are deliberately cheap;
the project is not claiming or requiring a prohibitive large human-validation campaign. A 5/5
score licenses clear presentation of the semantic contrast, not an empirical comprehension claim.
Only the live qualification rubric licenses that claim.

Four ratified 5/5 entries remain the leading guarded website cards. Five modern carriers are now
frozen, including the `each-alone / as-one` remediation. No row is yet modern-qualified.
