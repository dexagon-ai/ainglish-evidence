## A concrete prospective choice

The next narrowly scoped original could fix one complete rendering grammar:

```text
no-undo: ACTION irreversibly.
can-undo: ACTION; reversible via PATH[ by HOLDER only][ within WINDOW][; cost COST].
```

That fixes the English genre before any target counting. No per-pair choice
between `restorable`, `reversible`, `irreversibly` and `irrevocably`, and no
post-count choice of whichever spelling gives the desired delta. Punctuation,
articles, optional-slot order, active/report balance and handling of temporal
arguments must also be fixed in the complete renderer, not left to a replica.

However, a deterministic template is not automatically meaning-complete:

- Reversibility is under the writer's stated reach at write time, not omniscient
  knowledge of every possible future recovery mechanism.
- `can-undo` must name a documented path to the state **immediately before** the
  action. A partial restoration or older snapshot is not silently admitted.
- Where `HOLDER only` is used, exclusivity must actually be part of the shared
  case; merely naming a holder is not necessarily an assertion that no other path
  or holder exists. Otherwise choose the nonexclusive grammar prospectively and
  label that as a different fixed population, never add `only` only to English.
- The writer-default holder, expiry/window and cost facts must be equal in both
  arms. Any common reference schema is the same in both; excluding it from the
  measured span needs an explicit stable unit-span statement.
- The existing source still says `loss` in its comparison prose although the
  current proposal has no loss slot. Preserve that historic string in the old
  manifest. A new original should describe its actual population without it.

The candidate is **one permitted short English genre**, not proof that it is the
shortest possible complete English expression. If the author retains a minimum
over several English alternatives as the scientific estimand, list all admissible
alternatives and the selection/reducer rule *before* counting, and return every
alternative's outcome. A single chosen genre cannot be relabelled a proven minimum.
Whether that changes the declared claim needs author/governance review first.

## Boundary before a new experiment

Ask Reticuli and the original measurer to approve the complete semantic scope and
which estimand is intended. Then read exact-target suggestions: do not file a new
token original merely because an old token disagreement exists if the live task
instead requests reader confirmation. Any approved new scientific original uses
fresh complete inputs, its own comparison identity and estimand, normal preflight
and mint-before-first-count. Its replica uses the same renderer contract with new
inputs. Existing rows, thresholds and settlement histories stay visible.

No computation in this directory selects English wording based on its token cost.
