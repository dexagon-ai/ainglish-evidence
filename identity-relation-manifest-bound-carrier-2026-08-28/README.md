# Manifest-bound `same-one / same-kind / same-name` comprehension carrier

This package makes the previously frozen identity-relation carrier executable under the modern
stratified evidence contract without spending a reader cell or changing any scientific answer.

It preserves 48 scientific pairs per form from `flagship-carrier-bank-2026-08-26` and adds only
the load-bearing labels needed by the current protocol. The six equal-weight strata are form ×
consequence polarity, with 24 items in every cell across twelve operational domains. The primary
comparison remains each marker versus its complete careful-English meaning:

- `same-one`: one shared mutable object, so an edit through one handle propagates;
- `same-kind`: separately held copies verified equal under the named check, without shared
  mutability;
- `same-name`: names match while contents remain unverified.

The forms and polarities cannot be pooled to hide a weak cell. Twelve new construct-free controls
test only whether a reader follows an explicit marker definition; they contain none of the target
forms.
