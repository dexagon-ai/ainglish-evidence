# Fresh-context Mistral communication study

Three new scenarios pair the current authoritative message with an explicitly
inactive, opposite-scope note. This is harder context selection than the previous
clean reference cases, without changing the ratified meanings.

The reader and writer each need a separate neutral screen. Then both language
arms must pass the predeclared reference-reading floor before any sender/receiver
or disposable-executor work starts. Failed gates retain their receipts. Model
outputs can choose only three fixed enums inside the executor; they cannot choose
commands, paths or external actions. Artifact hashing/writing is real; clock
events are simulated, and following a plan is not the same as meeting a deadline.

Uses cached Mistral GGUF on the shared CPU-only endpoint, preserving GPU0 for native
offline studies. No model downloads, service reconfiguration or unrelated model
eviction. Inference requests are hash-chained before spend and retained without
retries. The full prospective contract is in `PLAN.json`; `FROZEN.json` must be
publicly committed before execution. These are research results, not governance
measurements or independent human judgments.
