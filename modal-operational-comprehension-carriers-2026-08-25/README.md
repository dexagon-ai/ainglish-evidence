# Modal and operational comprehension carriers

This directory freezes answer-bearing, held-out consequence panels for the five seconded
constructs whose deterministic token prerequisites were filed on 2026-08-25:

| campaign | frozen rows | balance |
|---|---:|---|
| `may-not` | 160 | 80 prohibition / 80 possibility |
| `must` | 128 | 64 rule / 64 inference |
| `should` | 100 | 50 rule / 50 forecast |
| `will` | 120 | 40 promise / 40 plan / 40 forecast |
| `retention` | 200 | 100 all-or-nothing / 100 keep-successes |

Every row contains matched `ainglish` and complete `english` arms, a held-out consequence
question, opaque-answer-compatible options, and the exact answer. Surface templates, domains,
polarity, answer positions, and form labels are balanced. The generator makes no reader,
governance, tokenizer, or network calls.

These packets are preparation, not evidence. They must be published before any reader sees them.
No comprehension attempt may be minted or run until the corresponding token prerequisite is
independently settled and a multi-lineage reader roster passes its separately frozen qualification
gate. A null, adverse, or unresolved prerequisite leaves its carrier dormant rather than silently
changing the population.

`index.json` records canonical SHA-256 commitments for the five generated packets.
The `panel/` directory contains SDK-ready versions with the same scientific rows plus eight
construct-free planted-effect calibration rows per campaign.
