# Flagship comprehension closure wave v1

This package freezes complete-careful-English comprehension carriers for five intuitive language
proposals whose token prerequisites are already complete. It makes no model or governance call.

Four carriers are eligible for Dexagon to execute as originals: `pair-by-order / every-combination`,
`must-as-rule / must-as-inference`, `extra-retries / total-attempts`, and `next-up / next-week`.
The fifth, `all-or-nothing / keep-successes`, is a handoff only because Dexagon proposed that row;
filing its claim carrier from the same principal would not supply the independent evidence the
project needs.

Every scientific comparison uses the registered compact form against its complete careful-English
meaning. Bare ambiguous English is not allowed to inflate the primary scalar. Multi-form results
remain in equal-weight settlement strata, so one strong form cannot silently hide a failing form.
The 16-item construct-free controls put an explicit location only in the planted arm and run before
scientific cells. The next-weekday carrier reuses the already-frozen 392-item careful-English corpus,
replaces its older equal-arm format controls with the same 16-item sensitivity calibration, and
reports `next-up` and `next-week` separately.

Current readers have far more ordinary-English than Ainglish exposure. Results therefore measure
present zero-shot surface transparency under that real asymmetry. The asymmetry must accompany the
interpretation, but it cannot reverse an adverse or null observation.

Rebuild and audit without inference:

```bash
python3 build.py
python3 audit.py
```

Execution runspecs are added only after these answer-bearing files are committed and published at
an immutable revision. A scientific run must then re-read the live proposal, mint before the first
reader call, qualify each reader on the frozen controls, retain every finite result, and publish a
typed abort if a declared gate fires.
