# Local reader qualification, 4 September 2026

These target-independent screens qualify two already-installed, digest-pinned
local Ollama reader artifacts before using either reader on the new progression
campaign. They test recovery of explicit information against an unresolved
alternative and do not contain Ainglish constructs or target answers.

Each configuration is run once. A failed screen remains a failed receipt and is
not retried under the same configuration.
